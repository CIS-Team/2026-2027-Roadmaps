# Video Editing Learning Roadmap

**Adobe Premiere Pro & Adobe After Effects · 9 weeks**

A GitHub-friendly version of the original Video Editing Learning Roadmap. The weekly order, video tutorials, episode ranges, and practice tasks are kept aligned with the source document.

## How to use this roadmap

- Follow the weeks in order.
- When a week offers alternative learning paths, choose one path.
- For Week 3, watch **both** videos in full in the language you choose.
- Practice along with the instructor rather than only watching.
- Check the course website/dashboard for supplied footage, assets, task instructions, and submission deadlines.

## Weekly plan

| Week | Original topic | Main focus |
| :--: | :-- | :-- |
| 1 | Adobe Premiere Pro Basics | Learn the interface and basic editing |
| 2 | Premiere Pro Basics & Plugins | Continue the course and get introduced to plugins |
| 3 | Sound Design | Learn sound effects in the chosen language |
| 4 | Sound Effects Practice Task | Add suitable sound effects to supplied footage |
| 5 | Short-Form Editing Practice | Recreate a Premiere Pro reel tutorial |
| 6 | White Minimal Reels | Recreate a white minimal reel tutorial |
| 7 | Introduction to Adobe After Effects | Follow a complete beginner project |
| 8 | Deep Glow Effect | Install Deep Glow and recreate a UI text animation |
| 9 | Animation Composer | Install Animation Composer and recreate a motion-graphics reel |
