# Level 1: Beginner

[Back to overview](../README.md) · Next: [Intermediate](../02-intermediate/README.md)

**Goal:** go from zero to a small game you built yourself and published on itch.io. You learn version control, C# and the basics of Unity, then build something on your own. No experience is needed. This level takes about 8 weeks at 4-5 hours per week.

## Learning Path

| Week | Topic | Outcome |
|:--:|:--|:--|
| **1** | [Git and C# basics](#week-1-git-and-c-basics) | A GitHub account and a Unity project in a repository |
| **2** | [Player control](#week-2-player-control) | Mission 1 done, and your first itch.io page |
| **3** | [Basic gameplay](#week-3-basic-gameplay) | Mission 2 done |
| **4** | [Sound and effects](#week-4-sound-and-effects) | Mission 3 done |
| **5** | [Gameplay mechanics](#week-5-gameplay-mechanics) | Mission 4 done |
| **6** | [User interface](#week-6-user-interface) | Mission 5 done |
| **7-8** | [Capstone](#weeks-7-and-8-capstone) | Your own small game, published on itch.io |

------------------------------------------------------------------------

## Week 1: Git and C# basics

Learn the basics of version control, then get a fast introduction to C# inside Unity. The C# video is about an hour and covers most of what you need before starting Unity Learn, which will be the core learning resource in the beginner track.

| Topic | Resources | Learning Objectives |
|:--|:--|:--|
| **Git** | [Basic Git](https://youtu.be/mAFoROnOfHs) <br> [Git with Unity](https://youtu.be/tTIlDb71t2s) | Track your work with Git, push it to GitHub, and set up a Unity project so it works with version control. |
| **C# in Unity** | [C# in Unity crash course](https://youtu.be/Zrt0iEBBkRM) | Scripts, variables, functions, operators, conditions, loops, timing, connecting scripts, and fixing problems. |

**Task:** Create a GitHub account. Make a Unity project, follow along with the C# video, and push the project to a repository.

## Weeks 2 to 6: Unity Learn, Junior Programmer

These five weeks follow the first five missions of the [Junior Programmer pathway](https://learn.unity.com/pathway/junior-programmer) on Unity Learn. You only need Missions 1 to 5. Skip the rest of the pathway.

Because of the Week 1 video, none of this should be *completely* new.

**Task:** Finish Mission 1. Then create an itch.io account and publish your Mission 1 build. It will be rough. That is fine. Pick a username you would be happy to put on a CV, because it ends up in your portfolio.

## Weeks 7 and 8: Capstone

You now know enough to make your own game. For two weeks you build one, alone, with no tutorial to follow.

Pick a small game you can actually finish in two weeks. A clone of a simple classic (Pong, Flappy Bird, Snake) is a good choice. A small game that is finished is worth more than a big one that is not.

Your game should:

- Be playable from start to finish
- Have a title screen, a score or goal, and a game-over screen with restart
- Use sound and some visual feedback
- Be saved in your Git repository as you work

**Task:** Publish your game on itch.io with a title, a description and at least one screenshot.

------------------------------------------------------------------------

## Level 1 Checkpoint

- Write C# scripts that move objects, detect collisions and spawn things, without copying a tutorial line by line.
- Use Git to save and share your work.
- Build a small game with sound, effects and a working UI.
- **Checkpoint project:** your capstone game, published on itch.io with a description and a screenshot.

You are now ready for game jams and for the intermediate track. Keep your itch.io page: everything you make from here goes on it.
