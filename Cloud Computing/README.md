# DevOps Roadmap (Beginner)

> **A NOTE BEFORE YOU START:** I DO NOT encourage learning in Arabic. If you REALLY have to, go ahead, but I DON'T recommend it, and I ADVOCATE AGAINST it.

This is the order I suggest for the resources below. Do the stages top to bottom, and keep doing the KodeKloud labs alongside everything. Items marked (optional) can be skipped. Once you finish, move on to the [advanced roadmap](ADVANCED.md).

## Practice (throughout)

- [KodeKloud labs](https://kodekloud.com/studio/labs): free labs only for now. Do a lab in parallel at each stage.

## Stage 1: Foundations

1. **Linux Admin 1**: [Maharatech course](https://maharatech.gov.eg/course/view.php?id=2115)
2. **Bash**: [YouTube playlist](https://www.youtube.com/playlist?list=PLT98CRl2KxKGj-VKtApD8-zCqSaN2mD4w)
3. **Git and GitHub**: [DataCamp GitHub Foundations track](https://www.datacamp.com/tracks/github-foundations?utm_medium=organic_social&utm_campaign=sharewidget&utm_content=trackdetailpage&utm_source=copy)
4. **Networking**: [Crash course](https://www.youtube.com/watch?v=Lw8QFsYCexc&t=35s)

## Stage 2: Cloud

5. **AWS Cloud Practitioner (theory)**: [AWS Skill Builder](https://skillbuilder.aws/learn/94T2BEN85A/aws-cloud-practitioner-essentials/8D79F3AVR7)
6. **AWS CLI** (optional, but recommended): [YouTube](https://www.youtube.com/watch?v=PWAnY-w1SGQ)

## Stage 3: Containers and Infrastructure as Code

7. **Docker**: watch both videos. They're from the same playlist, and if you understand one you'll understand the other.
   - [Video 1](https://www.youtube.com/watch?v=ZZ10b63xnQc&list=PL2We04F3Y_42mOz2jsBqB_TOGIgaB8KkL&index=1&t=16s)
   - [Video 2](https://www.youtube.com/watch?v=zJ6WbK9zFpI&list=PL2We04F3Y_42mOz2jsBqB_TOGIgaB8KkL&index=2&t=2291s) (a bit outdated)
8. **Terraform**: [YouTube](https://www.youtube.com/watch?v=YcJ9IeukJL8&t=1s)

## Stage 4: System Design

9. **Intro to system design**: [YouTube](https://www.youtube.com/watch?v=SE2KF-vxvS0&t=277s)

## Stage 5: Practical AWS Projects

10. **AWS Zero to Hero**: [YouTube playlist](https://www.youtube.com/playlist?list=PLdpzxOOAlwvLNOxX0RfndiYSt1Le9azze)

Don't watch the whole playlist. Explore it and pick the essentials: the 3-tier project, Lambda, API Gateway, and any other fundamental projects that stand out.

While doing the projects, **do not use the console**. Build them with Terraform and use the documentation.
