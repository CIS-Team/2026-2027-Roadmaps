# CIS Cybersecurity Entry Roadmap 2027

## Network fundamentals

**Topics:** LANs and the internet, clients and servers, switches and routers, Wi-Fi, the TCP/IP model, IPv4 addresses, and simple subnetting, DNS, DHCP, NAT, TCP vs UDP, common ports and protocols, HTTPS, Wireshark, and basic troubleshooting.

### Resources

- Main course: [Cisco Networking Academy — Networking Basics](https://www.netacad.com/courses/networking-basics/how-routers-work). It is designed to teach foundational networking through modules and labs.
- Video: [Practical Networking on YouTube](https://www.youtube.com/@PracticalNetworking), especially its introductory networking and subnetting lessons.
- Optional reference: [Computer Networking: A Top-Down Approach](https://www.pearson.com/en-us/subject-catalog/p/computer-networking-a-top-down-approach/P200000013385/9780135415603), by Kurose and Ross. Assign selected sections, not the whole book.

### Practice

Build a small network in Cisco Packet Tracer; use Wireshark to inspect a DNS lookup and web connection; explain what happens when someone visits a website.

## Linux essentials

**Topics:** files and directories, paths, navigating the shell, reading documentation, copying and searching files, and editing text, users and permissions, processes, packages, services, logs, SSH basics, Bash scripting, and least privilege.

### Resources

- Main course: [Linux Foundation — Introduction to Linux](https://training.linuxfoundation.org/training/introduction-to-linux/). It covers command-line basics, networking, Bash, and local security principles; select the most relevant sections for the circle.
- Video support: [Learn Linux TV](https://www.youtube.com/@LearnLinuxTV), using its Linux Crash Course and Bash lessons.
- Book: [The Linux Command Line](https://linuxcommand.sourceforge.io/tlcl.php/index.php), by William Shotts. The author provides a free online edition.

### Practice

Solve as much as you can in [Bandit – OverTheWire problems](https://overthewire.org/wargames/bandit/bandit0.html). “Recommended target 1-25”

## Python programming

**Topics:** variables and types, conditionals, loops, functions, lists, dictionaries, and debugging, files, exceptions, CSV and JSON, regular expressions, modules, simple tests, command-line arguments, and Git basics.

### Resources

- Main course: [Python for Beginners - FreeCodeCamp](https://www.youtube.com/watch?v=eWRfhZUzrAc). Work through its lessons and problem sets at a steady pace.
- Reading and project ideas: [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/), by Al Sweigart or [Python for Everybody: Exploring Data in Python 3](https://www.py4e.com/book) by Charles Severance.

### Practice

- For Python: [Python Basics - TryHackMe](https://tryhackme.com/r/room/pythonbasics).
- For Bash Scripting: [Bash Scripting – TryHackMe](http://tryhackme.com/room/bashscripting).

## Security+ fundamentals

**Topics:** the CIA triad, risk, threats and vulnerabilities, phishing and social engineering, identity and access management, security controls, and secure design, monitoring and logs, incident response, vulnerability management, backups, network defenses, cloud security basics, policies, and security awareness.

### Resources

- Syllabus checklist: [CompTIA exam objectives](https://www.comptia.org/training/resources/exam-objectives). Use the newest Security+ objectives available when teaching this section.
- Video lessons: [SY0-601 Security+ by NetRiders](https://www.youtube.com/watch?v=dyKg_bQOXfU&list=PLky4bd7_03m8o1NB0j96OsxZs0KcKlgMO)
- [Professor Messer’s Security+ resources](https://www.professormesser.com/sy0-701-certification-course/). Match the video course to the objective version you choose.
- Optional guided labs: [TryHackMe Cyber Security 101](https://tryhackme.com/path/outline/cybersecurity101). Select rooms that reinforce the month’s material; check which activities are currently accessible without a subscription.

## Cryptography

**Topics:** encoding vs hashing vs encryption, symmetric and public-key cryptography, digital signatures, password storage, certificates, TLS/HTTPS, and key management.

### Resources

- Video: [Introduction to Cryptography](https://www.youtube.com/watch?v=5jpgMXt1Z9Y)
- [Introduction to Cryptography – Mohammed Tarek Video 1,2](https://www.youtube.com/watch?v=wIrHNBla4ns&list=PLeI2QhZHGbbgEeZI6eMS2jNXoqHhE9RF) . Use selected introductory concepts; the full course is more mathematical.
- Optional book: [Serious Cryptography](https://nostarch.com/serious-cryptography-2nd-edition), by Jean-Philippe Aumasson.

### Practice

- [Cryptography Basics - TryHackMe](https://tryhackme.com/room/cryptographybasics)
- [Cryptography for Dummies](https://tryhackme.com/room/cryptographyfordummies)
- [CryptoHack - Introduction](https://cryptohack.org/challenges/introduction/)
